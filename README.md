# English OS 3.0：八大规则与介词底层逻辑

一个面向英语学习者的离线优先、视觉化 HTML 互动课件。

在线地址：<https://2023anita.github.io/english-os-courseware/>

## 项目定位

这不是把中文逐词替换成英文的词汇表，而是一套帮助学习者先建立认知结构、再组织英语表达的学习系统。

课程始终围绕一条主线展开：

> **先看事件 → 搭句子骨架 → 选择观察视角 → 标记信息关系 → 逐层扩展 → 形成自然表达**

介词部分沿用同一套方法：

> **空间画面 → 核心关系 → 抽象延伸 → 高频 Chunk → 真实输出**

因此，English OS 八大规则和介词底层逻辑不是两份孤立的资料，而是同一个表达系统的两个层面：前者解决“句子如何搭起来”，后者解决“词与词如何建立关系”。

## 课程内容

课件保留原始学习手册的完整内容，并按学习路径重新组织：

1. **English OS 八大规则**：核心事件、句子骨架、主语视角、逻辑连接、积木式扩展、Fact → Opinion → Reason、对话规划，以及“高级英语来自信息组织”。
2. **介词总地图**：位置、路径、来源、目标、伴随、分离、边界、时间和抽象关系。
3. **十个核心介词**：`of / for / to / off / away / with / by / at / on / in`。
4. **扩展介词系统**：方向与路径、上下覆盖、前后群体、内外边界、时间、原因让步、比较排除等。
5. **高频易混组合与 Chunk**：例如 `for / to`、`by / with`、`in / on / at`、`arrive / reach`、`made of / from / with / by`。
6. **练习与附录**：画面判断、原因解释、English OS 重构、参考答案、一页速查表和每日训练模板。

## 为什么这样组织

英语表达的难点通常不是“没有一个更难的单词”，而是没有先决定：

- 发生了什么；
- 哪个词承载核心动作；
- 从哪个视角观察事件；
- 两个信息块之间是什么关系；
- 哪些信息需要保留，哪些信息应该后置；
- 介词是在表达点、面、容器、路径、来源、目标还是边界。

课件因此把抽象语法变成可观察的动作和空间关系，同时明确提醒：核心画面是记忆锚点，不是可以机械套用到所有搭配的万能公式；固定语块仍需通过真实输入和练习巩固。

## 本地运行

直接双击 `index.html` 即可打开；如果浏览器限制本地文件资源，可以在项目根目录启动一个静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 内容完整性

当前版本由原始 Word 学习手册生成，原文统计为 507 个段落、124 个表格。发布前已执行 HTML 结构检查、资源路径检查和原文内容覆盖检查；`content-map.json` 用于后续修改时追踪每个源内容单元对应的课件页面。

## 适用范围

本项目是英语学习与教学辅助材料，不替代正式语法教材、语言学研究或教师对具体语境的判断。介词的“核心画面”用于降低理解和记忆负担，实际使用仍应结合语块、语体、地域变体和上下文。
